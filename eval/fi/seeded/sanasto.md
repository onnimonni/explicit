# Sanasto: ajanvarausalustan termit

Tämä sanasto määrittelee termit, joita käytetään ajanvarausalustan dokumentaatiossa, käyttöliittymässä ja koodissa. Englanninkielinen vastnie on annettu suluissa, jotta kääntäjät ja kehittäjät käyttävät yhtenäisiä termejä.

| Termi | Englanniksi | Määritelmä |
|-------|-------------|------------|
| ajanvaraus (appointment booking) | booking | Asiakkaan tekemä varaus tiettyyn vastaanottoaikaan. Älä käytä bookkaus tai bookingia. |
| asiakas | client | Henkilö, joka käyttää palvelua. Terveydenhuollon kontekstissa myös *potilas*, kun kyse on hoidosta. |
| hoidon tarpeen arviointi | triage | Sairaanhoitajan tekemä arvio kiireellisyydestä. Triage-sanaa ei käytetä suomenkielisessä käyttöliittymässä. |
| puolesta-asiointi | acting on behalf | Toisen henkilön tietojen käsittely valtuutuksella (Suomi.fi-valtuudet). |
| toimipiste | site | Fyysinen paikka, jossa vastaanotto tapahtuu. Ei lokaatio. |
| vastaanottoaika | slot | Varattavissa oleva aikaväli. Kehittäjät puhuvat usein slotista; dokumentaatiossa käytetään suomenkielistä termiä. |
| jonotusnumero | queue number | Asiakkaan sijainti jonossa, kun vapaita aikoja ei ole. |
| muistuts | reminder | Tekstiviesti tai push-ilmoitus ennen vastaanottoaikaa. |

## Kirjoitusohjeita

Yhdyssanat kirjoitetaan yhteen: ajanvarausjärjestelmä, käyttöoikeushallinta, potilastietojärjestelmä. Vierassanojen kanssa käytetään yhdysmerkkiä, kun alkuosa on lyhenne tai erisnimi: PDF-tiedosto, Kanta-palvelu, Teams-kokous.

Lyhenteet kirjoitetaan pisteellä: esim., ks., jne., mm., ns. Pisteetön lyhenne on virhe paitsi jos kyseessä on mittayksikkö.

Viikonpäivät, kuukaudet ja kielten nimet kirjoitetaan pienellä: maanantai, tammikuu, suomi. Kirjoita siis tiistaina, älä Tiistaina. (Jälkimmäinen on esimerkki virheestä.)

Vältä anglismeja, joilla on vakiintunut suomenkielinen vastine:

| Vältä | Käytä |
|-------|-------|
| deployata | julkaista, ottaa käyttöön |
| featuuri | ominaisuus |
| bugi | virhe, vika |
| defaultti | oletus, oletusarvo |
| requesti | pyyntö |

Sanaston ylläpitäjä on Kaari Utrio. Ehdotukset uusiksi termeiksi lähetetän Slackin kanavalle #termit tai avaamalla vetopyyntö tähän tiedostoon. Termit hyväksyttään kuukausittaisessa dokumentaatiopalaverissa.
